# Agent Note: 底栏的左右附件独立配置

Status: implemented

## Problem

底栏将透明材质与左侧绑定，把有色 FAB 的投影、按压光斑和白色图标固定给右侧。仅移除右侧底色会继续走有色 FAB 的反馈，无法得到和透明按钮一致的效果。

## Decision

左右附件各自提供同一种动作配置。胶囊独立取材质，附件样式一并提供材质、投影、前景、形状和反馈，避免用颜色 Alpha 猜测该使用哪种投影。左右都可以使用[原厂底栏或有色 FAB 的参数](../bug-fix/2026-11-21-coui-bar-sampling-and-material.md)。

两个按钮的配置独立，绘制仍由底栏三主体渲染器承载。固定槽位、采样留白和融合索引由底栏持有，切换某侧的可见状态时，另一侧继续使用自己的动画。需要收起动画时宿主保留该侧配置并切换可见值，销毁配置时释放该侧动画。

## Alternatives considered

- 给右侧加透明开关和额外材质参数，迁移成本较低，但两侧仍需要不同接口。材质、图标和投影分散在多个参数后，调用方也更容易只覆盖其中一项。
- 用独立 FAB 作为通用插槽，宿主可以自由布局，但独立渲染节点无法继续参与底栏当前的共享采样和三主体融合。

## Consequences

宿主可以在任一侧设置透明、有色或自定义样式。Alpha 调用方需要迁移到动作配置。库内保留固定槽位，移除附件时胶囊宽度仍由同一布局规则计算。使用方式见[底栏组件文档](../../../../docs/components/navigation-bar.md#左右附件)。

两边样式互换、动画反向、移除一侧时另一侧的收放，以及自定义形状的边缘合成需在设备上验收。静态检查只覆盖配置到绘制与输入入口的路由。
