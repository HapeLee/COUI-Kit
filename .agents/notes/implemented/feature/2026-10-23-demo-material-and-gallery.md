# Agent Note: Demo 的 M3 装配与 COUI 展示

Status: implemented

## Problem

Demo 将设置开关都画成复选框，预设选择缺少单选语义，M3 导航通过禁用按钮表示当前页。展示虽已包含主要组件，但独立效果、公开预设和若干组件状态缺少可观察入口。

## Decision

Demo 的 M3 装配参考 Metric 的当前主题、AppShape、MetricSwitch、MetricCheckbox、顶栏搜索和导航契约，并使用用户指定的 android-material-design 技能核对组件语义和无障碍边界。系统动态色作为 Demo 的主题输入，页面与卡片分别采用 Metric 的表面层级。G2 形状、开关与 Capsule 依赖只放在 App，不引入公共 COUI 模块。

设置项使用同款 G2 开关，整行持有 Switch 语义与 InteractionSource；预设使用单选组；复选框示例保留独立的 Checkbox 语义和禁用态。M3 导航使用标准 NavigationBar / NavigationRail 的选中态，横屏切为侧栏。搜索使用当前 Metric 同款受控 InputField 接口，处理焦点、键盘与返回；COUI 搜索同时演示退场与常驻操作。页面和分组分别保存示例状态，切页或筛选不重置已调整的受控值。

COUI 展示覆盖所有现有 UI 组件族及可独立观察的视觉效果：菜单增加图标、分隔、禁用项和长列表，滑条覆盖可见分段及隐式步进；阴影可选择全部轮廓并切换便捷与低层接口；补齐背景采样、模糊、材质混色、表面轮廓、背景感知轮廓、全部跟手光预设、形状、按压形变及三类状态反馈。底栏左右附件独立控制，顶栏按钮可禁用，原有 FAB 配色、融合与内容遮罩继续可交互展示。

局部背景示例使用各自的采样源，源内只有不透明背景图案，效果面板作为兄弟节点；顶栏、底栏和 FAB 保留在页面源之外。公共库接口与算法不因演示需要改变。

## Alternatives considered

- **让全部设置继续使用 COUI 复选框。** 改动少，但开关与单选意图不清，也不能验证对应的 M3 交互。
- **直接依赖 Metric 的 Design System。** 可以复用项目组件，但独立 Demo 会重新依赖原工程及其配置、主题和业务资源。
- **只列出效果名称或增加不可操作的占位卡片。** 不能观察真实输入、绘制和状态，因此直接调用公开能力生成交互示例。

## Consequences

App 展示源码按主题、公共控件、主要组件、视觉效果、阴影和运动分开，入口及展示范围由根 README 维护。平台条件沿用各公开 API；不为旧平台伪造 GPU 光效。低层调试探针与内部 Shader 辅助逻辑通过所属组件观察，不视作独立 UI 组件。

静态检查覆盖 Kotlin/KTS 语法、COUI 公开导入及参数、Demo 内部调用、所有分组的搜索入口、双语资源及格式参数、M3 状态语义、文档引用和模块边界。Material3 接口按版本目录对应的本地源码核对。未执行 Android 构建、Gradle Sync 或设备验证；大字体、TalkBack、真实焦点、触摸、GPU 绘制及视觉结果仍由用户验证。
