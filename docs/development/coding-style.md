# 代码规范

公开接口命名、参数顺序、默认外观、状态契约与失败分层见 [API 设计](api-design.md)。

## Kotlin 与 Compose

- 文件使用 UTF-8（无 BOM）。标识符、格式与声明顺序沿用所在组件族；库 KDoc、解释性注释、开发文档及提交说明使用简体中文。
- 无状态预设使用 `object`，归属对应组件族 Defaults。核心不读取应用偏好或 `MaterialTheme`；`coui-material3` 仅按[外观与预设](../guide/appearance.md)在消费处桥接 `MaterialTheme`。
- 列表身份使用稳定且唯一的 `key`。绘制范围与命中范围分别确认，渐隐或裁剪不能替代输入拦截。
- 整行承担交互时，子控件不重复绑定点击，保留禁用、键盘、焦点、TalkBack 与语义。
- 输入观察器不抢占点击或滚动，普通触摸提交保持唯一 owner。事件命名说明动作或结果；`CANCEL` 不提交业务动作；动画停止、父容器接管与节点移除须有对应收尾。
- 不为复用增加只转发参数的包装层。

## 资源、错误与绘制

- 背景、效果与业务状态分离。每个独立绘制节点各自持有可变 `renderer`，动画、监听与图层随节点释放，不建立全局历史缓存。
- 不吞错误、不模拟成功、不新增静默降级。`Shader` 创建失败交给宿主处理并决定替代 UI；协程捕获 `CancellationException` 后重抛。
- 禁止新增 `!!`。
- 用户文案进入所属模块字符串资源，默认英文并同步已有简体中文。库不依赖应用日志框架；需要诊断时用回调而非逐帧日志。
- 不为单个组件升级无关依赖或引入另一套样式框架。

## 注释与示例

- 注释说明依据、约束、非直观意图和接口契约，不复述代码或记录修改历史；原厂符号与当前适配分开标注。
- Demo 只调用公开 API；示例与文档编写同步遵守[文档维护规范](documentation.md)。
